# 缪胥衍与冰淇淋 · 安全小课堂

适合小学低年级的交互安全故事。四页共 24 格，每格点击后直接播放对应的动态故事，讲解结束进入选择题。答错可重选，答对后由孩子主动进入下一个故事。

## 当前体验

- 24 个画格共用完整的动态故事流程，包含选中画格推近、镜头缓慢移动、逐段对白、总结与选择题。
- 人物头像代替「谁说」的文字标签。缪胥衍用绿色，冰淇淋用黄色；完整说话人名称保留在无障碍描述中。
- 第一格精修信号灯和来车重点镜头，提供猫咪声音试听和可下载视频。
- 支持播放、暂停、继续、重播、拖动进度、分段查看、返回地图与减少动态效果偏好。
- 手机提供单独的大字号对白；文字和头像都位于主图之外。
- 老师和家长可以为每一格替换人物或猫咪的完整录音。录音存储在本机浏览器，不上传；刷新后保留，也可恢复默认。字幕按录音总时长分配，尚未进行逐词音文对齐。

当前动态效果是图片镜头运动、头像轻微动态和字幕切换，角色身体动作与口型尚未制作。第一格猫咪为本机合成试听声音，人物真人录音等待提供；其余故事目前按字幕节奏播放，尚无默认配音。

## 本地运行

需要 Node.js（运行环境）20.19+ 或 22.12+。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

入口为 `/`，故事深链接为 `/#story-1` 至 `/#story-24`。既有 `/#motion` 链接仍能打开第一格。直接访问深链接时等待手动播放，点击画格时自动播放。

```sh
npm run build
npm test
```

构建位于 `dist/client/`。仓库包含托管打包适配，但推送仓库并不等于公开部署网页。

## 第一格视频与声音

```sh
npm run motion:stills
npm run motion:render
npm run motion:all-stills
```

视频渲染需要本机 FFmpeg（音视频工具）。网页和视频导出共用分镜及画布渲染代码，默认第一格 25.7 秒、1920 × 1080、每秒 30 帧。导出会更新 `public/motion/safety-scene-01.mp4`、封面和字幕；`/motion/watch.html` 提供独立播放。

下载视频使用仓库内默认猫咪试听声音。浏览器中导入的个人录音仅用于网页，不会自动进入下载视频或仓库。其他 23 格已提供网页动画，尚未逐格导出视频。

`scripts/make-cat-voice.py` 可在已安装中文语音的 macOS（苹果电脑系统）上重新生成第一格试听，使用本机语音合成，无需网络接口。使用前请确认试听音色与语速符合课堂要求。

## 文件组织

- `src/App.jsx`：故事地图、分页、深链接和统一播放入口。
- `src/motion/StoryPlayer.jsx`：所有故事的播放、音轨同步和录音替换。
- `src/motion/story.mjs`：按原问答和录音时长生成时间线。
- `src/motion/render.mjs`：网页和视频共用的场景、镜头与头像对白渲染。
- `src/characters.mjs`、`src/SpeakerAvatar.jsx`：角色头像与颜色。
- `src/LessonQuiz.jsx`、`src/quizzes.mjs`：24 题、重选提示、答对反馈。
- `src/scenes.json`：24 组原问答和对应场景；`src/voices.json`：默认音频及实际时长。
- `public/avatars/`、`public/scenes/`、`public/audio/`：运行所需素材。
- `production/media-notes.md`：头像与声音来源、处理提示及当前限制。
- `design-qa.md`：本轮验收记录。

原始需求文档、历史输出、个人录音、环境配置和本机截图不进入仓库。现有内容与图片来自用户提供的项目素材，首次公开提交未另行授予素材使用许可。
